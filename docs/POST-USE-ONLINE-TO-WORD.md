# 用后即评线上综合分析与 HTML 月报

> 用后即评功能、分析模块与数据口径见 [DESIGN-用后即评.md](./DESIGN-用后即评.md)。本文只写「线上分析 vs 月报」的交付边界。

## 两份东西，不要合成一份

- **线上综合分析**是权威分析层：在任意时间范围内看证据、下钻、建举措。工作台故事页保留图表、清单和弹窗。
- **HTML 月报**是单月对外交付稿：独立文档页，在线阅读与交互（图表悬停、原话下钻），表格由同一套月报模型算出且不可改；总判断、问题结论、建议动作和章节显隐可编辑并保存。

不再生成或回导 `.docx`。线上交互是主路径；可用「导出离线 HTML」得到一份自包含快照，双击用浏览器打开，不依赖登录。需要纸质/PDF 时仍可用浏览器打印。

## 数据范围

| 内容 | 线上范围 | 月报取值 |
| --- | --- | --- |
| 用后即评评分 | 当前时间范围内、已开启用后即评分析的产品 | URL 月份对应的线上结果 |
| 客服部回访 | 按导入时选择的数据月份跟随当前范围 | 与报告月份相同 |
| 产品目录 | 当前生效的产品与规格配置 | 复用线上目录版本 |
| 问题变化 | 当前月与其之前最近一个有数据月份 | 截止报告月计算，禁止引用未来月份 |
| 举措 | 当前产品范围内的举措 | 本月提出、本月关闭及效果验证 |

历史客服部回访记录若没有 `importMonth`，兼容使用 `visitMonth` 作为数据月份。

## 单一计算链路

`故事模型 → buildMonthlyReportPreviewModel → HTML 报告页 + 叙述覆盖层`

报告页禁止另写指标。数字和证据表锁定；覆盖层只保存叙述与显隐，不写入表格数字。再打开时现算表格再套覆盖层；若数据已变，提示「表格已按最新数据刷新，叙述仍是上次保存」。

## 入口

工作台在**单月**时显示「打开月报」，新标签打开 `/workbench/post-use-report/:month`。该路由挂在登录与 Insights 之下，不走带侧栏的 AppShell。工作台已登录则新标签沿用当前会话，不必再登。权限与工作台相同；保存需要 `editRecord`。非法月份或当月无评分时页内说明，不生成空稿。

工具栏「导出离线 HTML」把当前画面（含未保存的叙述）打成自包含 `.html`：内联 CSS、SVG 图、原生折叠附录，无外部脚本、无需登录。文件名 `用后即评月报-YYYY-MM.html`。离线稿是锁定快照，不能再编辑保存。给未登录同事看，用这份文件，不要发在线月报链接。

## 文档结构

读者打开后连续读完三件事：现在怎样、问题在哪、这个月干什么。

1. **本月判断**（不可整章隐藏）：云网均分（相对公司均分高低、相对上月环比）、样本量、9 分以下产品数、投诉回访不达标产品数；评分分布、客户声音、产品均分、高频原因与趋势图（可交互）；正/负反馈原话对照（可点进反馈库）；一段可编辑总判断，首次用故事模型 `conclusions` 打草稿。
2. **问题与证据**：每条含状态标签、可编辑结论、锁定证据（均分相对 9 分线、非 10 分、问题变化、最多 3 条负向原话、同产品正反馈、回访证据数）、可编辑建议动作。最多 5～8 条，其余进附录。
3. **本月要办**：本月提出 / 关闭的举措、已完成未恢复、建议回访摘要；可编辑备注。
4. **附录**（默认折叠，打印默认不带，除非勾选「打印附录」）：整体得分表、评分分布、场景×旅程、需求、客户与回访明细、原因聚合、有效客户原话登记。

## 客户原话

统一过滤函数供负面纳入、原话登记和报告证据共用：

- 评分类 / 选项类：反馈原因列表（缺省回退 `commentText`）
- 短信：整体补充评价
- 投诉回访：电话回访意见
- **不用**不满原因冒充原话

无效文本：`无`、`无/不涉及`、`/`、`业务使用完毕`、`其他`、`nan`、纯数字、纯字母。通过过滤后再按是否与固定原因清单全文相同，分成反馈选项与客户原话。

正负先对齐「10 分满意 / 非10分」，10 分自由文本再看语义（复用工单情绪分析）：

- **负反馈**：问卷固定原因选项；或有效自由文本且得分不是 10（无分也按负）；或有效自由文本得分为 10 但语义为负
- **正反馈**：有效自由文本、同一条记录得分为 10，且语义不是负

均分与 10 分率仍按得分，不因原话改判而改分。问题条优先挂负向原话（没有再挂最多 2 个反馈选项），同产品正反馈只收语义仍为正向的 10 分原话。本月判断用交互图表展示评分分布、正/负条数、产品均分和趋势，并各摘最多 3 条原话（可下钻反馈库）。附录登记表含正负列。
