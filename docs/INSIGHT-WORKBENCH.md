# 洞察工作台 — 内容说明

路由：`/workbench`（登录后默认首页）  
职责：按**洞察周期**汇总多来源反馈快照，阅读结论与行动建议，并按来源下钻图表。

---

## 1. 页面顶栏

| 控件 | 说明 |
|------|------|
| **洞察周期** | 月 / 季 / 年 / **自定义起止月**；同一批导入数据可切换不同时间窗口 |
| **生成 / 刷新洞察** | 重建当前周期的洞察快照（导入或打标变更后需刷新；后台任务进行中时禁用） |
| **导出 PDF** | 按当前 Tab（综合概述或分来源）导出汇报材料 |
| **标签管理** | 跳转标签复核入口 |
| **洞察分析** | 进入 `/workbench/analysis`，按维度进一步下钻 |

快照过期时会出现黄色提示条，可点「立即更新」。当前周期无任何来源数据时，引导前往「数据导入」。

---

## 2. 一级 Tab 结构

```
综合概述 | 投诉工单 (n) | 咨询工单 (n) | 用后即评 (n) | 用户调研 (n) | 其他 (n)
```

| Tab | 能力成熟度 |
|-----|------------|
| **综合概述** | 完整：行动建议、万投比表、来源概览、跨源趋势 |
| **投诉工单** | 客户体验类万投比趋势、工单量趋势、情绪、问题分布、特性数量趋势、典型问题 |
| **咨询工单** | 同投诉结构，无客户体验类万投比趋势 |
| **用后即评** | 可用：评分概览 + 回访满意度（待整体重构） |
| **用户调研 / 其他** | 仅导入入库 + 条数占位 |

---

## 3. 综合概述（`overview`）

（本期未改）行动建议、各产品万投比表、各数据来源概览、跨源月度趋势。

---

## 4. 投诉 / 咨询工单 Tab

筛选：**产品**（下拉直接选择，含「全部产品」）。

### 4.1 时间口径

| 模块 | 时间口径 |
|------|----------|
| **客户体验类万投比趋势、工单量趋势、特性类型数量趋势** | **月 / 季 / 年**：所在年 1–12 月；**自定义**：起止月之间（含） |
| **用户情绪、问题分布、典型问题** | 当前所选洞察周期 |

### 4.2 模块（自上而下）

| 区块 | 说明 |
|------|------|
| **客户体验类万投比趋势** | 仅投诉；单折线 `cxRatio`；选中产品时叠加设置中的目标基准线；跨年取趋势窗**最晚年**目标 |
| **工单量趋势** | 总数 + 负面（趋势月窗 + 当前筛选） |
| **用户情绪分布** | 周期内 scoped 记录 |
| **问题分布** | Segmented：请求场景 / 问题类型 / 一级旅程（周期内） |
| **按特性类型看数量趋势** | 折叠面板；维度含场景 / 问题类型 / 旅程 L1/L2 |
| **典型问题** | 复用概览行动建议面板（按周期 conclusions + 产品同步） |

---

## 5. 用后即评 Tab

（本期不动）全部产品维度评分与回访满意度。

---

## 6. 洞察分析（`/workbench/analysis`）

（本期不动）请求场景、投诉原因、问题类型、用户旅程、用户情绪、高频词。

---

## 7. 核心概念

| 概念 | 说明 |
|------|------|
| **洞察周期** | 月 / 季 / 年 / 自定义起止月；与导入「数据月份」应对齐 |
| **趋势月窗** | 与周期统计窗可不同：月季年看全年，自定义看所选区间 |
| **洞察快照** | 按周期预计算；变更后需「生成 / 刷新洞察」 |
| **客户体验类万投比** | 投诉原因一级（终判）= 客户体验类 的投诉量 ÷ 月订单数 × 10000 |

---

## 8. 与周边模块的关系

```
数据导入 → 自动分析打标 → 反馈库复核
                ↓
         生成 / 刷新洞察
                ↓
         洞察工作台（本页）
           ├─ 综合概述 / 分来源图表
           ├─ 洞察分析（细拆）
           └─ 导出 PDF
                ↓
         举措与进展（闭环跟踪）
```
