# 洞察工作台 — 内容说明

路由：`/workbench`（登录后默认首页）  
职责：按**洞察周期**汇总多来源反馈快照，阅读结论与行动建议，并按来源下钻图表。

---

## 1. 页面顶栏

| 控件 | 说明 |
|------|------|
| **洞察周期** | 月 / 季 / 年 / **自定义起止月**；同一批导入数据可切换不同时间窗口 |
| **生成 / 刷新洞察** | 重建当前周期的洞察快照（导入或打标变更后需刷新；后台任务进行中时禁用） |
| **导出 PDF** | 按当前 Tab（综合概述或分来源）导出汇报材料 |
| **分析维度** | 跳转标签复核入口 |
| **洞察分析** | 进入 `/workbench/analysis`，按维度进一步下钻 |

快照过期时会出现黄色提示条，可点「立即更新」。当前周期无任何来源数据时，引导前往「数据导入」。

---

## 2. 一级 Tab 结构

```
综合概述 | 投诉工单 (n) | 咨询工单 (n) | 用后即评 (n) | 用户调研 (n) | 其他 (n)
```

| Tab | 能力成熟度 |
|-----|------------|
| **综合概述** | 完整：行动建议、万投比表、来源概览、跨源趋势 |
| **投诉工单** | 完整分析故事：综合结论、投诉规模与万投比、趋势变化、发生位置、痛点与需求、影响证据、行动与效果验证 |
| **咨询工单** | 完整分析故事：综合结论、咨询负担与自助机会、趋势变化、发生位置、痛点与需求、影响证据、行动与效果验证 |
| **用后即评** | 可用：评分概览 + 回访满意度（待整体重构） |
| **用户调研 / 其他** | 仅导入入库 + 条数占位 |

---

## 3. 综合概述（`overview`）

（本期未改）行动建议、各产品万投比表、各数据来源概览、跨源月度趋势。

---

## 4. 投诉 / 咨询工单 Tab

筛选：**产品**（下拉直接选择，含「全部产品」）。

### 4.1 时间口径

| 模块 | 时间口径 |
|------|----------|
| **客户体验类万投比趋势、工单量趋势、特性类型数量趋势** | **月 / 季 / 年**：所在年 1–12 月；**自定义**：起止月之间（含） |
| **用户情绪、问题分布、典型问题** | 当前所选洞察周期 |

### 4.2 分析故事（自上而下）

| 区块 | 说明 |
|------|------|
| **范围与可信度** | 当前范围、来源、产品、有效工单、快照及聚类版本；只在异常时提示 |
| **综合结论** | 整体状态、首要风险/机会、最大变化、行动缺口，均可跳到依据 |
| **规模与体验现状** | 通用工单与负向指标；投诉增加万投比和回访，咨询增加重复咨询与自助优化机会 |
| **趋势与变化** | 投诉量/万投比或咨询量/负向占比，以及问题新增、增长、持续、缓解、消失 |
| **问题发生位置** | 请求场景 → 一级/二级旅程 → 问题类型；投诉另含终判投诉原因 |
| **原因与用户需求** | 来源快照痛点聚类、改善优先级、客户请求和根因；咨询另分四类优化机会 |
| **影响与证据** | 高价值客户、负向、紧急催办、回访未解决及代表工单，可打开详情 |
| **行动与效果验证** | 聚类问题与举措合并；支持创建举措并识别已完成但未改善 |
| **分析附录** | 数据质量、分析口径、规则版本及异常明细下载 |

## 6. 洞察分析（`/workbench/analysis`）

（本期不动）请求场景、投诉原因、问题类型、用户旅程、用户情绪、高频词。

---

## 7. 核心概念

| 概念 | 说明 |
|------|------|
| **洞察周期** | 月 / 季 / 年 / 自定义起止月；与导入「数据月份」应对齐 |
| **趋势月窗** | 与周期统计窗可不同：月季年看全年，自定义看所选区间 |
| **洞察快照** | 按周期预计算；变更后需「生成 / 刷新洞察」 |
| **客户体验类万投比** | 投诉原因一级（终判）= 客户体验类 的投诉量 ÷ 月订单数 × 10000 |

---

## 8. 与周边模块的关系

```
数据导入 → 自动分析打标 → 反馈库复核
                ↓
         生成 / 刷新洞察
                ↓
         洞察工作台（本页）
           ├─ 综合概述 / 分来源图表
           ├─ 洞察分析（细拆）
           └─ 导出 PDF
                ↓
         举措与进展（闭环跟踪）
```
