# 06 · 环境启动与部署

> 起服务、发版、排障时必读。出处日期随条目标注。

## 1. 本地启动

- **一律 `npm run dev:clean`**（沙箱 NODE_OPTIONS/代理坑已修的干净启动方式），后台运行；前端 5175，API 3001。
- 验证：`curl --noproxy * http://localhost:3001/health` + 前端 5175 可访问。
- 管理员密码在 `.env` 的 `ADMIN_INITIAL_PASSWORD`（.env 不入库，勿提交）。
- **排障铁律**：服务未运行时看到的现象 ≠ 当前代码+数据的产出——先 lsof / health 探测进程在不在，不在则现象来自旧进程/旧数据窗口，转向"构造最小复现验证当前代码"（11-09 先例：3001 未运行时 preview「未标注产品」只能来自早前进程）。

## 2. 部署拓扑（11-10 落地实录）

- 生产站 81 = `/etc/nginx/conf.d/feedback.conf`，server_name 10.64.3.250，root `/liyujia/feedback-yw/dist`，client_max_body_size 20m。
- 测试站 82 = feedback-test.conf，root `/liyujia/feedback-yw-test/dist`——**用户拍板不同步缓存策略**。
- 仓库内 `docs/nginx-feedback-insights.conf` 已对齐生产实况（81 拓扑示例），Nginx 配置以它 + `docs/DEPLOY.md` §4.3 为准。

## 3. 发版缓存三件套（11-09/11-10 修复"同事发版后看到旧版"）

1. **Nginx 三层缓存**（DEPLOY.md §4.3 照抄）：`/assets/*` immutable 1y（指纹化资产）→ `index.html` no-cache → SPA fallback no-cache；流水线产物目录 deny。
2. **前端版本探针**：`src/lib/versionProbe.js`（指纹 = DOM 资产路径排序拼接）+ VersionRefreshBanner（挂载即探测 + 5min 轮询比对，刷新用 location.replace 带穿透参数保留路由；dev 形态无 /assets/ 引用一律 no-op）。
3. **dist 产物清理**：`scripts/clean-dist-artifacts.mjs`（白名单幂等）挂 postbuild。

验证 curl 六条：index.html no-cache / assets immutable / API 401 / 产物 403 / health ok / SSE 缺 Bearer 报错（报错=链路通）。

## 4. 端口与 API 拓扑注意

- **API /health 挂根路径**（server/index.js），**不在 /api 前缀下**——Nginx 反代验证用 `:81/api/auth/me` 看 401，勿用 `:81/api/health`（404）。
- MCP SSE 无凭证 curl 得 `{"error":"缺少 Authorization Bearer Token"}` 是**正常契约行为**；真实连接用应用内签发的 `fi_live_` 前缀 Key。

## 5. MCP / 邮件通道

- MCP 对外暴露走 desensitize（默认 true），详见 03 文档 §7。
- 邮件发送通道：授权码机制（非登录密码；服务端 create 必填校验，校验顺序在唯一性检查之后）。
- 群组模型：收件人必填非空、抄送人可空（cc_emails_json，加列迁移见 05 文档 §2.3）。

## 6. 部署后生效检查清单

改完服务端代码，部署机上要生效 = **拉代码 + 重启 API 进程**——进程未重启时新逻辑不生效（11-10 遗留：新预导入逻辑生效前提是重启，当时未确认）。

## 7. 运维脚本（scripts/，诊断+修复二合一惯例）

| 脚本 | 用途 |
|---|---|
| `visit-dispatch-reconcile.mjs` | 回访 dispatch 幽灵标记诊断/修复（--fix 清除 / --fix --backfill 补建 / --mark-imported 补标 via=import_backfill 可回滚 / --trace 溯源月份漂移）；`--db` 参数惯例对齐 ticket-gate-check.cjs |
| `audit-shared-predicates.mjs` | 共享谓词绕过扫描（exit 1 可接 CI） |
| `clean-dist-artifacts.mjs` | dist 产物白名单清理（postbuild） |
| `plan-c-daily.mjs` | Plan C 数据代理日包脚本（env 加载/持久库/组包推送） |

**部署数据修复流程先例（11-10）**：先诊断（只读）→ 按需 --fix / --backfill → 溯源侧确认后处理；修复宣称完成前终态数字必须有实测证据（查询输出），修复脚本 changes=0 必须 exit 1。
