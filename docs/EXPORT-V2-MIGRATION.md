## 2. 旧版 → v2 对照

### 2.1 保留或改名的列

| 旧版列名 | v2 列名 | 说明 |
|----------|---------|------|
| 工单号 | 工单号 | 不变 |
| 客户请求内容 | 客户请求内容 | 不变 |
| 需求痛点 | 需求痛点 | 不变；仍 fallback `problemSummary` |
| 请求场景 | 请求场景 | 不变 |
| 问题类型 | 问题类型 | 不变；**≠** 投诉原因（终判） |
| 用户旅程一级 / 二级 | 同左 | 不变 |
| 用户情绪 | 用户情绪 | 中文标签（如「不满」） |
| 是否加急 | 是否加急 | 加急时为「加急」，否则空 |
| 产品技术优化 | 产品技术优化 | 不变 |
| 服务流程改进 | 服务流程改进 | 不变 |
| 人工复核举措 / 优化方案等 | **确立举措** | 见 §2.3 |
| — | **排期** | 新字段 `actionSchedule` |
| 受理内容（原 raw/解析） | **受理内容** | `extractAcceptanceTextFromFields` |
| 处理意见（快照或字段） | **处理意见** | `extractHandlingTextFromFields` |
| 根因 / 根因（人工复核） | **根因排查** | `rootCauseReview` 或 effective 回退「问题原因」 |

### 2.2 已移除列（v2 不再导出）

| 旧版列名 | 处置 |
|----------|------|
| 时间 | 移除（非分析往返字段） |
| 投诉原因（终判） | 移除；终判仍在工单详情 B2 只读展示 |
| 投诉原因 一级/二级/三级（终判）（快照列） | 移除 |
| 客户请求来源 / 痛点来源 / 优化建议来源 | **库内保留**，不导出（§一.3） |
| 客户原话 | 移除 |
| 问题摘要 | 合并到「需求痛点」 |
| 根因 | 由「根因排查」+ 问题原因回退替代 |
| 优化建议（汇总） | 由产品/服务优化 + 确立举措替代 |
| 根因（人工复核） | legacy，停止写入 |
| 优化方案（人工复核） | legacy，停止写入 |
| 人工复核举措 | → **确立举措** |
| 问题原因 / 优化举措/建议（快照列） | 不单独导出；内容体现在处理意见/根因排查等 |

### 2.3 确立举措过渡

| 存储字段 | 导出列 |
|----------|--------|
| `establishedAction`（优先） | 确立举措 |
| `manualReviewOptimization`（fallback） | 确立举措 |

旧数据仅有「人工复核后的优化建议」时，导出仍会有值。

### 2.4 根因排查

| 优先级 | 来源 |
|--------|------|
| 1 | `rootCauseReview`（人工保存） |
| 2 | `sourceColumns['问题原因']` |
| 3 | `rootCause` |
