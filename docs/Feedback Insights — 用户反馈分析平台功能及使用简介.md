# Feedback Insights — 用户反馈分析平台功能及使用简介

**Feedback Insights** 定位是一站式用户反馈分析与洞察工作台，用于把投诉/咨询工单、用后即评等多源反馈导入系统，自动分析与打标，再在工作台汇总结论、跟踪产品优化举措。

---

## 平台能做什么

| 能力 | 说明 |
|------|------|
| **多源数据导入** | 支持投诉工单、咨询工单、用后即评、用户调研等来源 |
| **自动分析与打标** | 提取客户请求、需求痛点、优化建议；按产品旅程、请求场景、问题类型等维度打标（规则 + 可选大模型） |
| **人工复核** | 在工单详情中核对分析结果、标签、根因与投诉原因终判 |
| **洞察汇总** | 按洞察周期生成快照：整体结论、万投比、痛点聚类、行动建议（规则还在调优） |
| **举措闭环** | 将反馈关联到产品举措，跟踪排期、状态与需求工单 |
| **配置与治理** | 标签库、产品规格、万投比指标、数据备份、审计日志 |

---

## 标准使用流程

系统内置五步流程（登录页也有说明）：

```
1. 数据导入          → 上传 Excel/CSV 原始反馈
2. 自动分析与打标    → 导入后系统自动执行
3. 人工复核与确立举措 → 反馈库打开工单，核对并关联举措
4. 查看聚类与整体建议 → 洞察工作台 / 洞察分析
5. 跟踪举措进展      → 举措与进展
```

## 主要功能模块

### 1. 洞察工作台（首页）

按**洞察周期**查看分析结果，是日常看板入口。

- **整体概览**：各来源数据量、情感分布、整体结论与**行动建议**（含痛点聚类 V2；规则还在调优）
- **分来源 Tab**：投诉工单、咨询工单、用后即评等分别下钻
- **投诉 / 咨询主题证据**：本页只展示高风险抽样；整簇点「查看簇内 N 条」去反馈库（大簇一枚花片，不把工单号填进筛选框）
- **投诉专项**：万投比、投诉原因分布、用户旅程热力、痛点聚类等
- **洞察周期切换**：顶部选择分析月份/季度
- **生成 / 刷新洞察**：数据或打标变更后重建快照
- **导出 PDF**：生成汇报材料

**洞察分析**：按产品、旅程、关键词等进一步下钻，支持批量重打标（需权限）。

---

### 2. 反馈库

全部工单的列表与检索中心。

- 多条件筛选：产品、问题类型、旅程、情感、投诉原因等
- 从看板跳入时：小簇用 URL 工单号；大簇用「筛选 N / 库内匹配 M」花片过滤（不回填工单号多选）。N 与 M 不一致表示名单里有工单已不在库内
- 点击行打开**工单详情抽屉**：
  - **工单内容**：原文、处理意见、回访满意度等
  - **工单分析**：客户请求、需求痛点、优化建议、根因排查（自动 + 人工复核）
  - **工单分类**：请求场景、问题类型、旅程、投诉原因终判等
- **导入分析结果**：按工单号覆盖已有分析字段（Excel）
- **导出分析结果**：导出当前筛选结果
- **重新打标**：单条或批量（编辑者及以上）

---

### 3. 数据导入

导入原始反馈 Excel/CSV（编辑者及以上可见）。

- 选择**数据来源类型**与**数据月份**
- 列映射、预览、去重（同类型 + 同月份 + 同工单号 → 跳过）
- 导入后自动跑分析与打标流水线
- 支持用后即评、回访满意度等专项导入

---

### 4. 举措与进展

产品优化举措的管理台账。

- 按产品、状态统计举措数量
- 维护：问题描述、举措详情、排期、状态、关联工单号
- 支持 Excel 导入/导出
- 与反馈库工单可双向关联

---

### 5. 对象与标签

维护打标体系（编辑者可改，部分角色只读）。

- **产品配置**：目标产品与规格
- **请求场景 / 问题类型 / 用户旅程**：通用与分产品标签
- **LLM 标签复核**：审核模型提议的新标签

---

### 6. 设置

按角色显示不同 Tab：

| Tab | 内容 |
|-----|------|
| 大模型 | 本机 LLM 连接（浏览器本地保存） |
| 分析与打标 | 团队共享打标规则（管理员） |
| 万投比指标 | 产品月订单数、万投比目标（编辑者） |
| 数据管理 | 导出备份 / 清空数据 |
| 审计日志 | 导入、清空、改密等操作记录 |
| 漂流瓶 | 用户提交的优化建议与新点子 |

---

### 7. 用户管理（仅管理员）

创建用户、分配角色、重置密码、禁用账号。

## 角色与权限（简要）

| 角色 | 典型用途 |
|------|----------|
| **管理员** | 用户管理、团队分析配置、全部数据操作 |
| **编辑者** | 导入、打标、改数据、对象与标签、删数据 |
| **部分编辑者** | 查看 + 编辑单条工单/举措 + 导出 |
| **查看者** | 只读浏览与导出 |

## 快速上手建议

1. **首次使用**：管理员在设置中配置大模型（可选）与万投比分母；在对象与标签确认产品/旅程配置。
2. **每月例行**：数据导入 → 等待自动打标完成 → 反馈库抽样复核 → 刷新洞察 → 工作台看结论。
3. **闭环跟踪**：复核时在工单详情确立或关联举措，在「举措与进展」维护状态。
4. **协作注意**：导入/重打标/清空数据会占用后台任务，期间部分保存操作会暂不可用；团队共享配置约 5 秒同步。

---

## 辅助功能

- **漂流瓶**：右下角浮钮，随时提交优化建议或新点子
- **密码策略**：密码满 3 个月需修改；登录页或侧栏均可改密
- **备份与迁移**：数据存服务端 SQLite，支持导出 JSON 备份迁移
