# 打标配置（Excel）

维护 **`打标配置.xlsx`**，保存后在「设置」点击 **重新加载配置**。

在「标签管理」中的在线编辑写入**共享库**；写回本目录请使用页顶 **「发布打标配置」**（需 admin/editor）。发布后可在「设置」或各标签 Tab 中 **从 Excel 重新加载**。

## 工作表

| 工作表 | 说明 |
|--------|------|
| **填写说明** | 用途、填写要点与示例（含请求节点路径拆分案例） |
| **产品识别** | 每产品一行 |
| **用户旅程** | 按产品Key；旅程与主题标签只维护此表 |
| **请求场景** | 全平台共用，无产品Key（V2.0 共 9 类，与问题类型同级） |
| **通用问题类型** | 全平台共用，无产品Key |
| **请求节点-服务类型** | 可选；工单路径**第 3 段** → 旅程一级 |
| **请求节点-问题子类** | 可选；工单路径**最后一段** → 旅程一、二级 |

## 请求节点示例

工单原文：

```text
请求节点：undefined--弹性公网IP--产品使用问题--公网IP绑定/解绑失败
```

按 `--` 拆分：

| 段 | 内容 | 填哪张表 |
|----|------|----------|
| 1 | `undefined` | 忽略 |
| 2 | `弹性公网IP` | 产品段（配合「产品识别」） |
| 3 | `产品使用问题` | **请求节点-服务类型** 表（列「请求节点服务类型」须完全一致） |
| 4 | `公网IP绑定/解绑失败` | **请求节点-问题子类** 表（列「请求节点问题子类」须完全一致） |

**请求节点-服务类型** 示例行：`eip | 产品使用问题 | operate | 日常运维与访问`

**请求节点-问题子类** 示例行：`eip | 公网IP绑定/解绑失败 | bind | 绑定与网络配置 | bind-resource | 绑定/解绑云资源`

一级/二级 **ID** 必须与「用户旅程」一致；服务类型/问题子类文案与工单一致即可，不必等于旅程名称。

默认**不使用**请求节点；仅在「设置 → 旅程打标」勾选兜底且正文未识别时，按上表**精确对照**（无语义模糊匹配）。

```bash
npm run generate:taxonomy-xlsx
```

该脚本从各产品 `*.json` 与 **`REQUEST_SCENES_BUILTIN`（9 类 V2.0）**、**`PROBLEM_TYPES_BUILTIN`（12 类）** 生成 Excel；sheet 顺序与「发布打标配置」一致。决策树逻辑在 `src/lib/requestSceneClassifier.js` / `src/lib/problemTypeClassifier.js`，与 Excel 关键词保持同步。

在线编辑的权威数据在共享库；发布后或跑脚本后，若需生产包与 `public/` 一致，请再执行 `npm run build` 更新 `dist/`。

**V1→V2 标签更名**（如 `报障与恢复` → `报障与排错`）：已有工单需 **批量重新打标** 后洞察统计才会使用新分类结果。
