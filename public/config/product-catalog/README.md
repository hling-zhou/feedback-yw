# 目标产品与产品规格配置

## 文件

| 文件 | 说明 |
|------|------|
| `产品规格配置.xlsx` | **推荐** 维护方式，应用优先加载 |
| `product-catalog.json` | JSON 备用（无 Excel 时加载） |

## Excel 工作表

1. **填写说明** — 字段说明与示例  
2. **目标产品** — 每行一个分析目标产品（约 8 个）  
3. **产品规格** — 每行一个规格，用「产品Key」关联产品  

### 目标产品列

| 列名 | 说明 |
|------|------|
| 产品Key | 唯一标识，如 `eip` |
| 产品名称 | 展示名，如 `弹性公网IP` |
| 是否启用 | `是` / `否`，仅「是」参与导入分析 |
| 旅程模板Key | 对应 `打标配置.xlsx` 中的产品Key |
| 接受产品名匹配 | `是` 时工单规格列填产品名也可导入 |

### 产品规格列

| 列名 | 说明 |
|------|------|
| 产品Key | 所属产品 |
| 规格名称 | 标准规格名（入库值） |
| 匹配别名 | 逗号分隔，匹配工单「产品规格」列 |

## 生成 Excel

```bash
npm run generate:product-catalog-xlsx
```

从 `product-catalog.json` 生成/更新 `产品规格配置.xlsx`。

## 在线编辑与发布

在「分析维度 → 产品配置」中的修改会写入**共享库**（多用户自动同步）。若要写回本目录下的 Excel/JSON，请使用页顶 **「发布产品目录」**（需 admin/editor 权限）。发布后可在本页点击 **从 Excel/JSON 重新加载** 使运行环境读取磁盘文件。

## 路径说明

JSON 仅保留本目录下的 `product-catalog.json`（勿在 `public/config/` 根目录再放同名文件）。

## 生效

设置页点击「重新加载配置」，或重新导入工单前会自动加载最新文件。若已使用「本机可编辑配置」，以 IndexedDB 为准，文件作种子或「从 Excel/JSON 重新加载」用。
